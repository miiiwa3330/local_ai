以下に、PythonでスレッドセーフなLRUキャッシュクラスを実装したコードを示します。

```python
import threading
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()
        self.lock = threading.Lock()

    def get(self, key):
        with self.lock:
            if key in self.cache:
                value = self.cache.pop(key)
                self.cache[key] = value  # LRU
                return value
            return None

    def put(self, key, value):
        with self.lock:
            if key in self.cache:
                self.cache.pop(key)
            elif len(self.cache) >= self.capacity:
                self.cache.popitem(last=False)  # oldest item
            self.cache[key] = value

import threading
import time
import unittest

class TestLRUCache(unittest.TestCase):
    def test_lru_cache(self):
        cache = LRUCache(3)

        # put
        cache.put('key1', 'value1')
        cache.put('key2', 'value2')
        cache.put('key3', 'value3')

        # get
        self.assertEqual(cache.get('key1'), 'value1')
        self.assertEqual(cache.get('key2'), 'value2')
        self.assertEqual(cache.get('key3'), 'value3')

        # put (key1)
        cache.put('key1', 'new_value1')

        # get (key1)
        self.assertEqual(cache.get('key1'), 'new_value1')

        # put (key4)
        cache.put('key4', 'value4')

        # get (key2)
        self.assertEqual(cache.get('key2'), 'value2')

if __name__ == '__main__':
    unittest.main()
```

このコードでは、`LRUCache`クラスはキャッシュのサイズを制御するための`capacity`引数を受け取ります。キャッシュは`OrderedDict`で実装され、`get`および`put`メソッドは`threading.Lock`を使用してスレッドセーフに実装されています。

テストコードは、`LRUCache`クラスの基本的な動作を検証します。キャッシュのサイズが 3 に設定されている場合、キャッシュ内のアイテムの削除と再追加をテストします。

`LRUCache`クラスは、キャッシュ内のアイテムの削除と再追加を実現するために、`OrderedDict`クラスを使用します。`OrderedDict`クラスは、特定の順序でアイテムを保持するためのダブルリンクされたリストを内部的に使用します。アイテムを追加または削除すると、リスト内のアイテムの順序が変更されます。

`threading.Lock`クラスは、スレッド間で共有リソースへのアクセスを同期化するためのロックオブジェクトを提供します。`with`ステートメントを使用して、ロックを取得し、リソースへのアクセスが完了したらロックを解放します。

この実装では、平均時間計算量が O(1) であるため、`get`および`put`メソッドは効率的です。また、`threading.Lock`クラスを使用して、複数スレッドからの同時アクセスに対してスレッドセーフであることを保証します。
