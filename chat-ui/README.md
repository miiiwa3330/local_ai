# ⚡ Local AI Chat 環境マニュアル

このPC（Ryzen 5 3600 / GTX 1650 4GB / 8GB RAM）の限界スペックを徹底検証し、最適なローカルAI実行環境を構築しました。

---

## 🚀 使い方（2つの起動方法）

### 方法1: ブラウザでチャット画面を開く（おすすめ）
フォルダ内の **`Start-Chat.bat`** をダブルクリックするだけです。
* ブラウザが自動起動し、専用のモダンなチャットUI（`index.html`）が開きます。
* 画面左上の「モデル選択」から、用途に応じてモデルをいつでも切り替えられます。
* DeepSeek-R1の「思考プロセス（`<think>`）」の折りたたみ表示や、コードのハイライト・コピー機能、リアルタイム速度（tok/s）表示が備わっています。

### 方法2: コマンドライン（ターミナル）から使う
PowerShell または コマンドプロンプトから以下のコマンドを入力すると、直接対話できます：
```powershell
ollama run llama3.1:8b
# または
ollama run deepseek-r1:7b
# または
ollama run qwen2.5:3b
```

## 🛠️ VS Code や 他アプリ（API）との連携

Ollama は OpenAI 互換の API サーバーを提供しています。
* **エンドポイント**: `http://127.0.0.1:11434/v1`
* **APIキー**: 任意の文字列（不要、例: `ollama`）

VS Code の拡張機能（Continue、Cline など）や Python スクリプトから、通常の ChatGPT と全く同じように接続してコード補完やチャットが可能です。

### Python からの呼び出し例
```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:11434/v1",
    api_key="ollama"
)

response = client.chat.completions.create(
    model="llama3.1:8b",
    messages=[
        {"role": "user", "content": "Pythonでスレッドセーフなキューを書いてください。"}
    ]
)
print(response.choices[0].message.content)
```
